# Addresses you trust

Barkley can't know every host an app legitimately uses. A few findings are only about
**where an address points**: an internet address written into the code as a number, or an
address in a code library that an automatic check finds suspicious-looking.

On an app's page, such a finding offers **Trust for this app** and **Trust for every
app**. Check first that it is an address you expect the app to use.

## What trusting does

- The finding stays listed, under "Findings about addresses you trust", and stops
  costing points, now and in future sniffs, until the address changes. A new or changed
  address is flagged again.
- **Barkley's own score is always shown beside yours.**
- The stored scan is never changed. Trust is applied when a score is shown.
- Notifications say when a score counts addresses you trust as fine, and give Barkley's
  own score too.

## What can't be trusted away

Findings about **what** an app sends, and paste sites, tunnels and chat webhooks. Only
your own clicks create a trust mark; no list and no AI does.

## Undoing it

**Stop trusting** on the app's page, or the **Addresses you trust** page, which lists
every mark, for every app and per app.
